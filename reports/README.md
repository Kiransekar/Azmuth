# `reports/` — Generated reports

Date-stamped, machine-generated reports (tapeout audit §0.2). No hand-edited
reports live at the repo root anymore.

## Layout

```
reports/
├── latest -> YYYY-MM-DD     # symlink to the most recent set (rebuilt by flow scripts)
└── YYYY-MM-DD/
    └── <stage>/             # integration | phase3..6 | validation | floorplan |
        └── *.txt            #   coverage | pnr | sdk | sta | ...
```

Each report's first lines carry provenance: relocation date, `repo-commit`
hash, and original path. Reports produced going forward should be emitted by the
`flow/` scripts directly into `reports/<date>/<stage>/` and the `latest` symlink
re-pointed — not edited by hand.

## Current contents

`2026-05-23/` holds the historical Phase 3–6 validation, integration, final
validation, and floorplan-visualization reports that previously floated at the
repo root, each prefixed with a provenance header noting they were generated by
an earlier phase (pre-relocation, commit `96a282a`).
